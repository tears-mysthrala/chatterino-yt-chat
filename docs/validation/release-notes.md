# chatterino-yt-chat 1.2.0

Quality and diagnostics update for the read-only YouTube Live Chat viewer plugin.

### Highlights

- `▶️ YT` visibly identifies rich messages, system notices and text fallbacks.
- Synchronization delay now delays presentation through an ordered queue while
  polling continues at YouTube's requested cadence.
- New operational commands: `list`, `status`, `pause`, `resume`, `remove`,
  `config`, `export` and `import`, with completion support.
- Persisted state migrates automatically to schema v5 and preserves paused
  channels plus the selected language.
- Capability detection prepares image rendering for a future Chatterino stable
  release; Chatterino 2.5.5 keeps safe textual fallbacks.
- Spanish/English operational messages can be switched live and persist.
- Local health counters expose polling, retry, delivery and unknown-protocol
  behavior without collecting chat content.
- Validated avatars and stickers materialize automatically when the verified
  future Chatterino image API is present.

### Assets

- `chatterino-yt-chat-1.2.0.zip`
- `chatterino-yt-chat-1.2.0.zip.sha256`

The checksum is generated by the release job from the tagged commit. Always
verify against the `.sha256` asset from this release.

### Installation

1. Verify: `sha256sum -c chatterino-yt-chat-1.2.0.zip.sha256`.
2. Replace the plugin files in Chatterino's `Plugins/chatterino-yt-chat/`
   directory. Keep the `data/` directory.
3. Restart Chatterino and run `/yt-chat status`.

### Compatibility and limitations

- Chatterino 2.5.x; verified baseline: 2.5.5.
- Chatterino 2.5.5 has no plugin Settings GUI API and no public image creation
  API. Configuration is available through commands and validated JSON; remote
  images retain textual fallbacks.
- This release remains strictly read-only with respect to YouTube.

### Validation gate

Automated tests, lint, fixtures, reproducible packaging and a real Chatterino
smoke test are required before tagging. A long GUI soak remains a release
confidence check and must be recorded without overstating it as completed.
