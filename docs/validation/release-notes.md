## chatterino-yt-chat 1.0.0

Stable standalone release of the YouTube Live Chat read-only plugin for Chatterino.

### Assets

- `chatterino-yt-chat-1.0.0.zip`
- `chatterino-yt-chat-1.0.0.zip.sha256`

### Highlights

- Modular parser/renderer/action architecture.
- Safe unknown action/renderer fallback.
- Atomic persistent state with backup recovery.
- Bounded backoff and continuation-based polling.
- Automated test and release pipeline.
